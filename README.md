# LSAT Arena

Static ranked Logical Reasoning duel site. Open `index.html`, or visit https://dovigertelman-dot.github.io/lsat-arena/.

Same five LR questions, same clock. Accuracy decides the match; speed breaks ties. Rating, record, pattern stats, badges, and the daily streak stay in this browser.

- Ranked duels open with a 3, 2, 1, Go countdown. Tap an answer to select it, tap again to submit, or tap × to clear it.
- Pattern stats track accuracy and average time. Train weak spots draws questions from your lowest patterns.
- The daily challenge is the same five questions for everyone on a UTC date, with a streak.
- Bronze, Silver, Gold, Platinum, and Diamond follow your Elo. Badges mark a first ranked win, a 5-win streak, a perfect 5/5, and a 7-day daily streak.
- Challenge a friend with a link that replays your questions and compares the scores.
- The interface is a dark, Inter-set arena: rank emblems, mode cards, countdown, answer feedback, and a mute control for the optional sounds.

Files: `index.html`, `style.css`, `app.js`, `questions.js`.
